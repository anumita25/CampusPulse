## ⚠️ The Problem
Between lectures, labs, and assignments, students lose hours every week to unpredictability. Walking all the way to Darling Canteen only to find the line stretching out the door, getting stuck behind a 20-minute queue at Xerox in TT, or showing up to SMV to find the basketball courts fully occupied. This friction kills productivity and causes unnecessary stress.

## 💡 The Solution
**CampusPulse** eliminates campus guesswork. It is a mobile-first, real-time queue management and mobility dashboard that tells you exactly where to go and when to leave. We've digitized the campus footprint to transform how students interact with university infrastructure, saving time and optimizing crowd flow.

## ✨ Features
* **Virtual Queueing (Zero-Wait):** Claim a digital token for printing, canteens, or the mess. Your phone holds your spot so you don't have to stand in line.
* **Smart Routing & JIT Notifications:** Just-In-Time alerts calculate your walking distance against live queue speeds (e.g., "Leave now. 8 min walk gets you there as #47 is called").
* **Live Facility Leaderboards:** Need a printout fast? We rank all nearby print shops by a dynamic "Facility Score" that combines current wait times and your physical distance.
* **Interactive Spatial Map:** A sleek, custom-built vector map providing an at-a-glance, color-coded view of open sports grounds and active facilities.

## 🛠️ Technical Implementation
* **Frontend:** Pure HTML5, CSS3, and Vanilla JavaScript.
* **UI/UX:** Built entirely from scratch without bloated libraries. Features a custom dark-mode design system with fluid CSS keyframe animations (like live-status pulse waves) for a premium, native-app feel.
* **Architecture:** Zero dependencies and lightning-fast load times, engineered as a lightweight Single Page Application (SPA).

## 🗺️ Future Roadmap
* **Robust Database Architecture:** Transitioning from local state to a scalable cloud database (e.g., Firebase or MongoDB) to handle real-time crowd analytics, persistent queue state, and historical traffic patterns.
* **Vendor Command Center:** A dedicated, low-latency dashboard for facility managers (mess staff, print shop owners, canteen operators) to seamlessly advance tokens, update capacity limits, and broadcast live delays to the student network.
* **Secure VIT Authentication:** Implementation of a strict login gateway utilizing the student's VIT Registration Number and password. This prevents token spam, restricts access to verified campus residents, and paves the way for deeper integration with student timetables.
